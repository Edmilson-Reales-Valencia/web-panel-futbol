# Panel de posiciones de fútbol

Aplicación web para registrar resultados de partidos y consultar la tabla de posiciones de un torneo de fútbol. El proyecto está desarrollado con React y Vite.

## Requisitos

- Node.js instalado.
- npm, que se instala junto con Node.js.

## Instalación y ejecución

Abre una terminal en la carpeta del proyecto e instala las dependencias:

```bash
npm install
